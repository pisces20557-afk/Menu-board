# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR코드를 찍으면 휴대폰으로 보게 되는 **디지털 메뉴판 웹페이지**입니다.
파일은 `index.html` 하나이고, 설치나 서버 없이 브라우저에서 바로 열립니다.

## 주요 기능

- **카테고리 버튼**: 전체 / 커피 / 논커피 / 디저트. 누르면 해당 메뉴만 보이고, 처음에는 "전체"가 선택돼 있습니다. 버튼은 스크롤해도 화면 위에 붙어 있습니다.
- **사장님 추천 배지**: 추천 메뉴(지금은 아인슈페너, 흑임자 라떼)에 배지를 달고 카드를 살짝 강조하며, 화면 위쪽에도 따로 보여줍니다.
- **오늘 품절 표시**: 품절 메뉴는 흐리게 보이고 "오늘 품절"이 뜹니다.
- **전화 걸기 버튼**: 누르면 바로 전화 화면으로 연결됩니다.
- **매장 안내**: 영업시간, 휴무일, 주차, 좌석, 인스타그램.
- **휴대폰에 맞춘 화면**: 폭 390px 기준이고, 작은 폰(320px)과 가로 모드에서도 깨지지 않습니다. 길게 내리면 "맨위" 버튼이 나타납니다.
- **디자인**: 하늘색과 크림색 분필로 그린 칠판 스타일(분필 가루, 둥근 카드, 부드러운 그림자). 제목과 가격은 손글씨 글꼴, 설명은 고운 돋움입니다.

## 보는 방법

1. 이 저장소를 내려받습니다.
2. `index.html` 파일을 더블클릭하면 브라우저에서 열립니다.
3. 손님용 QR코드로 쓰려면 이 페이지를 인터넷 주소로 올려야 합니다. (예: GitHub Pages 같은 무료 호스팅)

> 손글씨 글꼴은 인터넷에서 불러옵니다. 인터넷이 없으면 고운 돋움이나 맑은 고딕으로 대신 보입니다.

## 메뉴를 고치는 방법

메뉴 정보는 `index.html` **맨 위쪽의 "메뉴 정보" 칸**에 모여 있습니다. 거기만 고치면 화면이 저절로 바뀝니다.
자세한 안내는 그 칸의 한국어 주석에 적혀 있습니다. 메뉴 한 줄은 이렇게 생겼습니다.

```js
{ 이름: "아메리카노", 가격: 4500, 설명: "산미가 적은 고소한 원두", 판매: 1, 종류: "커피" },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | `가격:` 뒤의 숫자만 바꿉니다. (원, 쉼표 없이 숫자만) |
| 이름·설명 바꾸기 | 큰따옴표 `" "` 안의 글자만 바꿉니다. |
| 메뉴 추가 | 같은 종류의 메뉴 한 줄을 복사해서 바로 아래에 붙여넣고 내용을 바꿉니다. |
| 메뉴 삭제 | 그 메뉴 한 줄을 지웁니다. (줄 앞에 `//`를 붙이면 잠깐 숨기기) |
| 사장님 추천 달기 | 줄 끝에 `, 대표: true`를 붙입니다. 빼려면 그 부분을 지웁니다. |
| 오늘 품절 켜기/끄기 | `판매: 1`(판매 중)을 `판매: 0`(오늘 품절)으로 바꿉니다. 다시 `1`로 바꾸면 판매 중입니다. |

> 줄 끝의 쉼표(`,`)와 큰따옴표가 하나라도 빠지면 화면이 비어 보일 수 있습니다.
> 고치기 전에 파일을 복사해서 백업해 두세요. 고친 뒤에는 저장(Ctrl + S)하고 새로고침(F5)으로 확인합니다.

가게 이름, 영업시간, 전화번호는 메뉴 정보 칸이 아니라 파일 아래쪽 화면 코드에 있습니다.
`Ctrl + F`로 "브릿지 커피", "08:00", "tel:"을 검색하면 찾을 수 있습니다.
(전화번호는 `tel:` 뒤의 숫자와 버튼 글자, 두 군데를 같이 바꿔야 합니다.)

## 색깔 바꾸기

`index.html`의 `<style>` 맨 위에 있는 색깔 설정(`:root`)의 `#` 숫자만 바꾸면 전체 색이 한 번에 바뀝니다.

## 파일 구성

```
메뉴판/
├─ index.html              지금 쓰는 메뉴판 전체 (HTML + CSS + JavaScript)
├─ index-칠판-전.html       품절·추천 기능을 넣기 전 칠판 디자인 (보관용)
├─ index-파랑.html          흰 배경 + 파란 카드 디자인 (보관용)
├─ index-갈색유리.html      갈색 + 유리 느낌 디자인 (보관용)
├─ index-품절0-1.html       품절을 0/1로 나타내던 옛 방식 (보관용, 숫자 뜻이 반대)
├─ 자료/
│  └─ 기획시트.png          가게 정보와 메뉴를 정리한 기획 시트
└─ README.md               이 문서
```

실제로 쓰는 파일은 `index.html` 하나입니다. `index-`로 시작하는 나머지 파일은 예전 모습을 남겨 둔 보관용입니다.

## 가게 정보

- 가게: 브릿지 커피 (광주 북구 비엔날레)
- 소개: 매일 직접 볶는 스페셜티 커피
- 영업시간: 평일 08:00 ~ 21:00 / 주말 10:00 ~ 20:00 / 목요일 휴무
- 전화: 062-000-0000 (예시 번호이므로 실제 번호로 바꿔 사용하세요)
